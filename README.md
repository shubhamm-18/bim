# Beyond Imagine Media (BIM) — Agency Workspace

A real estate agency operations and client management workspace built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Zustand**.

Inspired by the connected agency workspace prototype, built from scratch with clean, production-ready architecture designed for easy UI rebranding and database integration.

---

## 🚀 Key Modules & Capabilities

1. **Executive Overview Dashboard**
   - 4 Core KPIs: Client Projects, Due Tasks, Pending Approvals, Reported Site Visits
   - Priority Task Queue with `Today`, `Overdue`, and `Upcoming` tabs
   - 360° Service Modules fast switcher
   - Active Client Projects Data Table with live status chips
   - CRM Lead Conversion Snapshot and Attention Alert Center

2. **360° Real Estate Service Modules**
   - **Content Studio**: Script-to-screen production pipeline (`Idea` → `Script` → `Shoot` → `Edit` → `Approval` → `Ready to post` → `Posted`) with both Stage Board and Publishing Calendar views.
   - **Advertising**: Meta, Google & LinkedIn campaign tracking, ad spend, CPL, impressions, and leads.
   - **Automation & CRM**: End-to-end buyer journey pipeline (`New Lead` → `Contacted` → `Qualified` → `Visit Booked` → `Visit Completed` → `Booked`).
   - **Gruhnest Media & Listings**: Property profiles, sample-flat statuses, inventory tracking, media asset readiness, and estimated deal commissions.

3. **Management & Workflow Tools**
   - **Client Projects Directory**: Full directory categorized by developer accounts (Shakti Group, Sun Creators, Gruhnest).
   - **Tasks & Calendar**: Multi-role task scheduling with recurrence support (Daily/Weekly/Monthly) and priority tags.
   - **Approval Board**: Creative review board with one-click Approve / Request Changes workflow.
   - **Project Comparison**: Side-by-side metric benchmarking across projects.
   - **Payments & Billing**: Financial register tracking retainers, invoices, and disbursement status.
   - **Project Templates**: Rapid onboarding blueprints for new client launches.

4. **Productivity & Role Viewpoints**
   - **7 Role Perspectives**: Instant view switcher for `Founder`, `Project Management`, `Content`, `Video`, `Ads/Performance`, `Developer`, and `Sales`.
   - **Global Search (`⌘ K`)**: Real-time modal searching across projects, tasks, leads, and content.
   - **Workspace Filters**: Fast client filtering dropdown.
   - **Quick Action Modals**: Dedicated modals to create projects, assign tasks, and log leads.

---

## 🛠️ Getting Started

```bash
# Run local development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view your workspace.
